# Migrating away from GitHub

All good things come to an end. A google search will give you multiple reasons why this is a good idea, such as [GitHub rolling up under the AI division at Microsoft](https://www.theverge.com/tech/809889/github-agent-hq-platform-play-microsoft-jared-palmer-jay-parikh) which means we get [AI shoved down our throats](https://github.com/orgs/community/discussions/159749), etc. 

Personally, whatever little software I write for myself in my free time is now self-hosted (Gitea running on a small home server). Whatever smaller fraction of that needs to be made public will be hosted on [Codeberg](https://codeberg.org/hairband_dude). Repositories here will be archived, and repositories with no stars/watchers will be deleted. 

If you've not noticed already, the blog [has moved to being hosted on CloudFlare pages with quartz](https://aniruddhadeb.com).

See you on the other side.
